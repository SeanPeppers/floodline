Result 3 · the tool

P(flood) for any Key West street, by year, scenario and elevation.

A 3.0 ft street in 2050: 0.6149 a year, about 1 in 1.6. City-wide, 55.8% of 6,054 road points flood in an average year.

Run it

Everything runs on a simulator; only the hardware demo needs an IBM account.

uv sync
uv run python experiment.py        # two-driver benchmark
uv run python experiment_multi.py  # five-driver benchmark
uv run python experiment_wins.py dim  # 5-13 uncertain factors
uv run python floodline_cli.py --year 2050 --elevation 3.0 --exposure
uv run python hw_demo.py dry       # 3-qubit demo, noisy sim; "run" uses a real IBM QPU
